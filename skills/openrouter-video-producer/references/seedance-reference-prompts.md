# Seedance 素材綁定與提示詞

本文件提供 Seedance 2.5 的混合參考範例，查證日期為 2026-09-30。用途是協助建立素材責任與提示詞，不固定未來 API 的欄位、大小寫、編號、格式或數量限制。

## 以執行時規則重寫

使用 Seedance 前，核對選定模型、實際供應商、OpenRouter 最新提交 schema，以及供應商的素材指代規則。遇到 AI 提出不同規則時，先查證該規則的官方來源、模型版本與適用介面；經確認後重寫受影響規則，不照搬過期範例，也不僅憑 AI 的回答認定規格已改變。

- **OpenRouter 的請求格式以 OpenRouter 現行 API 為準。** 上游的 `content.role` 等欄位不一定能直接填入 OpenRouter 請求；需查證其映射或公開支援的供應商選項。
- **素材能力與模型指代以實際供應商為準。** 上游支援不等於路由介面已完整提供；欄位被接受也不等於模型確實採用素材。兩層有差異時，先解決映射，不能自行虛構轉換規則。
- **若規則改變，就同步重寫。** 更新素材對照表、API 輸入、提示詞中的指代與必要的本機驗證；不要只改文字卻保留舊提交順序，也不要只改欄位卻留下失效標籤。
- **保存變更依據。** 在影片專案紀錄保存模型／供應商、查證日期、官方網址、舊→新規則與尚未驗證的部分。確認為可重用的規格變動時，更新本 Skill 中受影響的參考文字；不要將單次輸出偏差升格為通用規則。
- **保留已確認的創作要求。** 規格更新只調整如何傳入與引用素材。若新規格無法滿足人物身分、聲音或預演要求，告知差異並解決需求，不靜默刪除。

遇到官方文件互相矛盾時，清楚區分 OpenRouter 與供應商介面、版本和未知事項。需要實際生成才能確認的行為，只在既有生成授權與預算範圍內驗證；記錄 API 接受與素材使用效果兩種證據，不用重複付費提交來猜規則。

## 三者一起建立

每個實際生成單元一起準備：素材對照表、`request.json`、提交用提示詞。對照表保存本機檔案、素材類型、API 欄位與項目順序、預計指代、採用資訊、排除資訊及查證狀態。

下面的 `@Image1`、`@Video1`、`@Audio1` 是 Seedance 上游官方指南中的指代方式。此處示範的混合素材編號經 OpenRouter 轉送後尚未實測；提交前核對實際映射與各類素材的編號方式，不把陣列總索引直接當成圖片、影片或音訊編號。未完成綁定時標示「預計指代」。

| 素材檔案範例 | 類型 | 預計指代 | 採用資訊 | 排除資訊 |
|---|---|---|---|---|
| `actor.png` | 圖片 | `@Image1` | 男主角臉部、髮型、服裝 | 設定圖版面與背景 |
| `living-room.png` | 圖片 | `@Image2` | 客廳外觀、材質、照明 | 不相關人物與文字 |
| `previs.mp4` | 影片 | `@Video1` | 分鏡、走位、運鏡、事件順序 | 代理模型外觀、簡化材質、預演原音 |
| `actor-voice.wav` | 聲音 | `@Audio1` | 男主角音色、語氣與說話方式 | 參考錄音原台詞與背景雜音 |

OpenRouter 的混合參考使用 `input_references`；目前官方範例中的圖片與影片分別以 `image_url`、`video_url` 項目傳入。聲音項目的完整 schema、供應商限制與指代映射須另查當下文件，不因名稱類似就猜出欄位。只有已實際傳入且規則已核對的素材，才能在交付時稱為已綁定。

一般混合參考不要同時加入 `frame_images` 來充當人物參考圖：首尾幀模式與參考模式用途不同，OpenRouter 文件指出首尾幀優先。需要鎖首尾幀時先核對混合模式實際能力，不承諾其他參考仍生效。

## 提示詞參考

以下是借用音色、生成新台詞的範例；標籤須在實際提交規則核對後替換。時長與輸出規格另放在 `request.json`，不要由這段範例推定。

```text
素材用途：
男主角的外觀與服裝依照 @Image1。
客廳外觀、材質與照明依照 @Image2。
@Video1 僅提供分鏡、人物走位、運鏡與事件順序；
不要沿用預演中的代理模型外觀、簡化材質或原音。
@Audio1 僅提供男主角的音色與說話方式；
本次台詞使用下方指定內容，不沿用參考音訊原本的台詞。

畫面與表演：
男主角走進客廳，在沙發旁停下，看向門口。
鏡頭依照 @Video1 的路線緩緩推近。
男主角以平靜、略帶猶豫的語氣說：「你終於回來了。」
說話時嘴形配合台詞，保留自然的停頓與呼吸。

臉部身分一致性：
男主角從首次露臉起維持 @Image1 的五官與辨識特徵，
跨角度、表情與遮擋保持同一身分。

聲音：
生成對白與客廳環境音，不加入背景音樂。
```

音訊至少分清三種用途：借用音色並生成新台詞、沿用指定台詞與節奏、參考音樂節奏或氛圍。只寫「參考聲音」不足以指定責任。若要求原錄音逐字、逐樣本保留，不把生成模型的參考能力當成原音直通保證；視已授權製作範圍安排後製混音。

多人物時，逐一指定人物到圖片及聲音來源的對照，不把所有圖片描述為一個人，也不把所有聲音混成同一位說話者。代理預演只提供結構；人物圖、場景圖與聲音分別決定外觀與音色。
