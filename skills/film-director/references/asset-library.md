# 資產庫（1.3）

只搜尋使用者已登記的資產庫根目錄與索引，不掃描整顆磁碟。Asset Browser 有列出資產，不代表效能、內容或授權已確認。以 `asset_id` 加版本為單位，分別保存原始下載檔、整理後的 `.blend`、LOD／代理版本、manifest 與授權文件。

## 可重用單位與版本

完整的 `location_set` 是預設可重用單位。保留拓樸、功能區、固定家具、比例、主要通道、門、碰撞與可通行區、站立／座椅／鉸鏈錨點、中性材質、實例化規則、LOD 及相依項目。不要只為建目錄就把賭場、公園、公寓、街道或辦公室拆到每張椅子與每面牆。只有實際重用需求、穩定獨立的造型／介面，或使用者明確要求時，才將小道具單獨升格。

精確沿用時鎖定已登記版本，例如 `LOC_CASINO_A@v001`。「同一間賭場」保留其拓樸與介面；「另一間賭場」則建立新的場所資產。場景專用的布置記為 `project_local_variant`，不可默默改動共用原件。永久變更場所時發布新版或衍生版；既有專案不自動升級。

重複的靜態內容用連結 Collection 或 Geometry Nodes 實例化。各自表演的角色需要獨立骨架，以及適當的 override 或 append；靜態 Collection Instance 無法讓每位角色各做不同動作。不要為了改一個人就把整個資產庫轉成本機副本。記錄缺少的資產／附加元件，必要時使用語意代理物件。

## 選擇性的升格流程

只有使用者表明需要重用或發布，而且靜態場景已確認後，才討論升格到資產庫。列出有編號的候選場所與包含範圍，再確認是保留在專案內、發布到指定共用資產庫，還是保留可編輯草稿。預設留在專案內。共用發布前檢查私人參考資料、第三方素材、附加元件與授權。

擷取場所的 Collection，不要擷取整個場景。排除目前及其他相機、時間軸標記、分鏡、鏡頭時長、角色、路徑、Follow Path、骨架、Actions、NLA、drivers、所有動畫、場景專用光線／天氣／色彩、劇本、連續性、提示詞、節奏及專案絕對路徑。保留場所結構、固定道具、語意介面、碰撞／導航、材質區域、效能代理及該場所自身的參考資料。

在空白 Blender 檔案測試載入。確認單位與朝向、根 Collection 與相依項目、材質／貼圖／LOD／實例、邊界、入口、通道及碰撞／導航錨點。檢查是否混入不應保留的故事或動畫資料。測試失敗就仍是專案草稿，不是可重用場所。新場景另加新角色、動作、相機、光線、天氣、標記、節奏及提示詞；可以利用場所介面，但不繼承舊表演。

使用[素材清單 Schema](asset-manifest.schema.json)。新場所資產採 `schema_version` 1.2；此 Schema 也可讀取舊版 1.1。記錄來源／版本／授權、單位、方向、原點、Collections、邊界、錨點、LOD 三角面數、材質／貼圖、相依項目，以及選用的 `location_contract`、`content_contract`、`promotion` 與 `validation`。角色紀錄包含骨架對應、IK 與身高；動作紀錄包含 FPS、時長、循環、根節點位移或原地動作、支撐階段與接觸事件。攻擊片段與受擊片段不會自動匹配。

## 專案圖片參考

使用者製作、購買或提供的場景／道具圖片是專案層級的圖片參考，不是可散布的 3D 資產。逐一登記在目前修訂版的 `asset_reference_manifest`，與 Asset Browser 項目分開。記錄 `asset_id`、`image_path`、`source_or_generation_tool`、`project_revision`、`reference_views`、`scale_anchor`、`extract_for_blender` 及 `do_not_copy`；也可記錄 `license_note`、`owner`、解析度、可信度與對應場景 ID。使用實際路徑，例如 `image-assets/casino_entrance_front.png`，並寫明要擷取的結構特徵；排除品牌、可辨識招牌與獨特藝術作品。

只擷取已登記的結構。單張圖片的透視、遮擋、誇張光線或看不見的背面，不能確立尺寸或拓樸。通道與相鄰關係須依場景約定、可靠平面圖及相關研究。`do_not_copy` 通常不應空白。照片或生成圖片本身不授予模型重建、商用、再散布或訓練權利。權利不明時保留限制，使用原創中性代理，或取得權利資訊。

Blender 建模前確認必要圖片存在、可開啟、不是空白佔位檔，有已登記來源與已確認修訂版，並附比例參照或明確不確定性；`extract_for_blender` 與 `do_not_copy` 須相容。預先建立的空檔案不是完成的參考圖。若條件不符，回報缺口與所需提示詞，不要先建受影響的場景或關鍵道具。缺少角色外觀不阻礙結構代理製作。

首批只納入目前鏡頭需要的資產。不要只為填滿目錄而安裝大型資產庫或戰鬥骨架。外部資產來源清單只是線索，不代表已下載或相容 Blender。使用前確認確切套件／版本與授權，特別注意免費、商用及再散布條款可能不同。
