# 圓柱與球形角色尺寸及彎曲標準（3.1）

本文件適用於新建立的預設代理角色。角色共用幾何類型與控制意義，不代表尺寸都相同。比例只是低成本預演的起點，不是解剖定律；已確認的舊專案不必自動重建。

## 尺寸

`H` 是從支撐面到頭頂的站立身高，單位為公尺。優先採用角色既定設定或可靠參考；若未知，依年齡、物種與體型估計，並標記 `height_source: production_estimate`，不可寫成角色既定事實。

| 參數 | 意義 | 起始值 |
|---|---|---|
| `total_height_m` | H | 依角色而定 |
| `head_diameter_m` | D | 成人 0.20H；兒童 0.25H |
| `body_diameter_m` | W | 成人 0.24H；兒童 0.26H |
| `body_length_m` | L = H - D | 圓柱從底到頂的長度 |
| `head_center_z_m` | L + D/2 | 球體與圓柱相切；預設無頸部或間隙 |
| `root_origin` | 圓柱底部的支撐點 | +Y 朝前，Z 朝上 |

若 H=1.75 公尺，成人 L=1.40、W=0.42、D=0.35 公尺；若 H=1.15 公尺，兒童 L=0.8625、W=0.299、D=0.2875 公尺。這只是計算示例，不是選角必用尺寸。非人角色可採其他比例與自然靜止朝向，但仍保留一個可彎圓柱及一個球體；預設不加四肢、角、尾巴或觸手。

在角色／SceneSpec 紀錄中保存 `character_id`、來源、H/W/D/L、球心、比例、朝向、幾何分段、骨架名稱與版本，跨集沿用。換衣服不重算身體尺寸；故事中實際成長或變形則建立新狀態。

使用[尺寸計算腳本](../scripts/derive_proxy_dimensions.py)進行不開啟 Blender 的離線計算；`<skill-root>` 是本技能 `SKILL.md` 所在資料夾：

    python "<skill-root>/scripts/derive_proxy_dimensions.py" --height 1.75 --preset adult --height-source production_estimate
    python "<skill-root>/scripts/derive_proxy_dimensions.py" --height 1.15 --preset child
    python "<skill-root>/scripts/derive_proxy_dimensions.py" --height 2.4 --preset custom --head-ratio 0.16 --body-ratio 0.28

此工具只輸出基礎圓柱／球體與四骨骼 JSON。選用接觸手部另有預算；工具不會建模或驗證模型。將輸出存入專案。

維護此輔助工具時，從 `skills/film-director/` 執行 `python -B -m unittest discover -s scripts -p test_proxy_dimensions.py -v`，測試檔為 [test_proxy_dimensions.py](../scripts/test_proxy_dimensions.py)。這些測試檢查尺寸計算，不驗證 Blender 骨架行為。

## 四骨骼彎曲骨架

沿同一圓柱，在 L 的 0、0.29、0.58、0.79、1.00 位置設置 `Lower`、`Upper`、`TorsoLower` 與 `TorsoUpper`。非人形態可調整並記錄。這些名稱表示同一身體的彎曲區域，不代表腿、手臂或頸部。

起始可用圓周 16 段、高度 40 區間（41 個環）的圓柱，以及 16×8 的低面數球體。須有足夠連續的環才能形成曲度；只有兩個環會像鉸鏈。權重跨多個環平順過渡。單側過渡寬度起點約為 0.07L，且不超過相鄰最短骨段的 40%。避免權重突變、嚴重體積流失與自體交錯。

球體以靜止姿勢偏移量跟隨上半身。道具錨點跟隨所屬軀幹區域。根節點路徑／朝向、局部彎曲及支撐高度各有獨立控制；骨架不新增第二套水平位移。骨長保持穩定。不要縮短整根圓柱或把它壓進地板來假裝坐下。

靜態建模時建立並綁定靜止姿勢，接著展示。只有靜態結果確認後才製作彎曲動畫。預設四骨骼不需要另行許可。鏡頭專用的接觸手部不授權細緻四肢、步態或全身 IK。獨立表演的角色須有獨立控制；遠景且一致的群眾可實例化骨架或沿用快取姿勢。

## 大動作姿勢與支撐

| 故事動作 | 結構表達 |
|---|---|
| 坐下或蹲低 | 彎曲上下區段、降低重心，確認地板與座椅支撐 |
| 倒向地面 | 彎曲膝／髖區域、降低重心，讓下半部落地並停留 |
| 躺下 | 整體轉向支撐面，配合彎曲與圓柱／球體淨空 |
| 起身 | 上半身蜷曲、下半部收攏、重心抬起並伸展；允許停頓 |

依實際地板、座面或坡道的高度與方向處理，不一律假設世界 Z=0。製作期間從受影響時段與鏡頭視角檢查變形後邊界及支撐；只有根節點高度或未變形的 bounding box 不足夠。局部取樣不能證明每格都無碰撞。沒有腳就不做細緻腳底固定審查。自然四肢支撐、步態、表情與呼吸寫入最終影片提示詞。使用者確認後不再增加姿勢複核。
