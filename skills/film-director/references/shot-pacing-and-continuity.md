# 鏡頭時長、接點與換場連續性

適用所有題材、參考路線與影片模型，不限定遊戲風格、角色、鏡頭數或全片時長。不新增逐鏡確認關卡，也不要求已接受的舊影片重做。

## 依動作安排時間

先分配「建立情境 → 動作 → 反應／結果 → 辨識或對白」所需時間，再選符合實際模型能力的生成單位。需要連續走位、互動或對白的鏡頭，可先以約 10 秒起草，再依節拍調整；簡單的一個動作、反應或空景仍可用較短鏡頭。不要把每鏡固定成 5 秒或一律延長到 10 秒。

動作生硬時先檢查是否塞入過多事件、缺少準備與收尾、走位矛盾或運鏡搶走辨識時間；延長片長本身不保證流暢。新增時間要重新安排事件與停留，不把既有影片等速拉長。使用者已固定全片時長時，先提出減少事件或重新分配時間的方案，不能自行延長整片。

分開記錄劇本／剪輯目標時長、API 請求時長及輸出實際時長。不要只為湊秒數而裁掉動作完成、對白、任務結果或需要看清的畫面；必要事件晚於預定切點時，保留來源，說明時間差並處理剪輯安排。生成單元與敘事鏡頭不必一對一，不能因為要做 15 秒就機械拆成三個 5 秒。需要拆分時選擇自然且能接續的動作邊界。

## 先分類接點，再定義狀態

| 接點類型 | 設計方式 |
|---|---|
| 同時同地的動作延續 | 保持動作因果、位置與速度，從上一段採用的結束狀態接續 |
| 同場景改機位 | 保持世界中的人物／道具關係，為新角度設計相容的開場 |
| 換地點、換時間或省略過程 | 以動作結果、環境交代、聲音或其他敘事線索說清楚跳接原因 |

在分鏡表或生成單元紀錄寫下上一段結束與下一段開始的狀態，以及哪些部分允許改變。依鏡頭需要記錄：

- 已採用人物、服裝、場景與關鍵道具的穩定 ID、版本；人物姿態、座位、持有物、手部接觸及道具開關狀態。
- 世界位置、路線、路口與地標關係、行進方向及速度；追逐中的領先／落後、接近／遠離等角色關係。不能只用畫面上方／下方代替世界中的前後。
- 攝影軸線、相機所在側、景別與切鏡理由；光線、時間、必要介面／任務進度、連續聲音及未完成對白。

換機位不等於換車、換人物或另造一條街。同一場景沿用已採用的外觀與空間來源。畫面左右可以因視角改變，但世界中的座位或位置不能無故交換；跨軸或轉向時提供能看懂方向變化的畫面。外景切到內景等合理切鏡不必強迫相機繞行或穿入物體。

## 用實際採用畫面接續

同一動作需要前段輸出才能接續時，按依賴順序生成。下一段可從前段**實際採用範圍的最後有效影格**準備起始參考：記錄來源影片／工作、修訂版、FPS、影格索引或時間、圖片路徑及雜湊。剪輯後的接點不一定是原始輸出的最後一格；不要拿未採用試片、舊版尾格或概念草稿冒充成片接點。

實際尾格取得前，依既有確認／委託記錄接續策略與預計開場，將依賴素材標為待補；可先交付規劃與草稿，後段提交須等實際來源備妥。選格後將它登記為下一單元目前採用的 `start_frame_visual_reference`，保存到專案資產區並複製到本包 `media/`；同步 `start_frame_reference_id`、`reference_ids`、manifest、提示詞、來源對照表及尚未提交的 `request.json`，重新核對素材配額與 API 模式。原先起始圖與已提交紀錄保留為歷史，採用清單對應本次實際輸入；這項接續整理沿用既有授權，不新增逐鏡確認。

同場景改機位時，依上述結束狀態準備新角度起始圖；尾格可提供狀態參考，不能要求下一段同時精確複製舊構圖又立刻換角度。換場則依新的地點與時間設計開場，不把所有接點都當成無切鏡延長。

實際尾格作為參考仍不保證模型精確承接。一般圖片參考與原生首／尾幀模式依已查證的介面能力選用；保留完整運鏡頁／預演與已選定人物來源，遵守素材配額，不能為加入尾格靜默刪除必要素材。詳見[起始畫面資產與數量規則](start-frame-assets.md)。

## 發現偏差時先修正接點

生成或剪輯工作中，針對受影響接點比對前段尾部與後段開頭；能播放時檢查接點附近的動作與聲音。靜態抽格只能支持構圖與狀態觀察，不能證明移動流暢、對白正確或全部參考已生效。沒有查看實際內容就保留未驗證，不以 API 成功代替品質判斷。

若結果把人物／道具換掉、追逐關係反轉、路線無故改變，或缺少必要動作，先記錄偏差並停止依賴該接點的後續提交；不要改寫故事替錯誤畫面找理由，再沿用錯誤尾格。準備局部修正，更新受影響的起始圖／分鏡／提示詞，保留未採用與採用版本。付費重做依既有明確授權範圍執行，範圍不足才詢問，不因本指引逐鏡重新要確認。API 或工具錯誤仍依所用生成 Skill 的錯誤流程辦理。

剪輯時在清楚的動作結果或相容狀態切接，避免重複同一動作、方向突然反轉或角色位置跳變。需要重疊影格時記錄使用範圍，組合後去掉多算的部分。轉場特效、淡化或拉長素材不能修復原本互不相容的場景；修正設計或生成來源，並如實交付實際時長與仍存在的偏差。這些檢查屬於本次生成／剪輯工作，不是參考素材確認後新增的導演核准關卡。
