# 角色走位與相機路線共同設計

預設預演建立根節點位移、畫面方向、距離、遮擋與相機路線。步態、腳底固定、全身 IK 與身體曲線驗收，只在 `previs_profile.character_motion_scope` 明確為 `articulated_performance` 時適用。局部接觸手部不會觸發全身要求。根節點位移不能稱為已驗證的奔跑。本頁檢查用於製作、修訂或使用者明確要求的複核，不在使用者確認後重新執行。

本指引用於奔跑、追逐、邊移動邊對白、打鬥換位、跟拍與長鏡頭。先讀導演意圖；身體動作參見[動畫與表演](animation-and-performance.md)。[來源索引](research-sources.md)列出 D01–D03、D07、B01–B07 及 P01。下文的路線表示、數值方法與檢查是本 Skill 的工程應用，須在實際場景測試。

## 可行動的空間與運動控制權

使用公尺、Z 軸向上；角色預設面向 +Y。分別定義畫面、相機局部、物件局部與世界座標軸。在圖上標出可通行區、高度、障礙邊界、門、遮擋物、出入口、起點、路標、停止點、接觸點、角色朝向、相機通道與動作軸線。只有平面圖不能驗證樓梯、跳躍或垂直攻擊。

先排表演者路線，再選相機視角，兩者可為畫面反覆調整。移動應改變距離、可見性、控制權或接觸條件。記錄 `path_id`、`owner_id`、`coordinate_space`、`waypoints`、`time_marks`、停步／轉身／接觸事件及 `facing_policy`。路徑經過目的地，不代表在正確影格抵達。

一般地面移動須在最終 `.blend` 保留可編輯 Curve 路徑。記錄 `curve_id`、物件、控制點、方向、時間對應、朝向策略與事件。空間路線與時間曲線分開。

| `motion_owner` | 用途與限制 |
|---|---|
| `static` | 無根節點位移或無用途的 Curve；允許明確的根節點旋轉 |
| `curve_follow_path` | 預設自主移動；根節點只有一個有效 Follow Path，不得同時有競爭的 Location driver 或 parent 位移 |
| `parent` | 車輛、電梯或其他載具帶動；宣告 parent 與局部錨點，不同時加入根節點路徑／位置移動 |
| 指定其他來源 | 記錄物件、時段、自由度與原因；不支援的 Fast 驗證標為未驗證 |

同一時間每個位移自由度只能有一個來源控制。來源切換時，宣告切換前後控制權、交接影格及世界變換如何保留。記錄 Follow Path 的 `offset_factor` 或時間對應、前／上軸及 `use_curve_follow`。撤退、側移或看向別處時，朝向可與行進方向不同。引導路徑與標記不出現在最終參考影片中。

## 角色路線與時機

速度依比例、地形、可用時間與情緒設定。以路徑距離和時長檢查不合理的位移；沒有通用奔跑速度。用路徑弧長 `s(t)` 分配起步、巡航、轉彎、煞停與接觸。不要每個路標都緩入緩出。轉彎要有可通行曲率或刻意減速、全身朝向變化與重新加速。向心加速度 `v²/r` 可協助評估轉彎，不能證明步態真實。

倒退、側移或回頭看時，朝向與速度分開。速度為零時保留明確朝向，不對零向量做正規化。追逐中比較雙方隨時間的進度、間距與遮擋。切鏡不能重設地理關係。接觸前先估算接近速度。

Blender 5.2 的 Follow Path 以取樣後的累積弧長評估位置，因此靜態且比例正常的路徑使用線性因子，可近似等弧長前進。不可斷言原始 Bezier 參數一定導致變速。但非等比縮放、變形或移動中的曲線、控制者偏移與後續 Constraint，仍可能改變最終世界速度。應取樣最終動作；只有必要時才建立世界弧長查找表或 Bake。引用的實作使用第一條 spline，多 spline 路線須合併或明確管理。

## 相機路線與平順轉彎

相機要有獨立且可通行的路徑，不是剛性綁在角色根節點上。側跟呈現速度與距離；正面後退能看到臉與身後的人；後跟揭示路線；四分之三跟拍兼顧體積與方向；固定機位讓移動速度有參照；跟拍轉揭示則須定義何時離開原主體，以及新的注意目標。

候選相機位置可由角色位置 `P(t)`、前向 `T(t)`、連續側向 `N(t)` 與上向 `Z` 推出：`C(t) = P(t) + aT(t) + bN(t) + hZ`。這只是一個候選值；轉彎、停步、障礙與敘事上的分離都需要修正。最終相機須有自己的路線與時間。注視目標可以是胸口、頭部、多人加權中心或空間錨點。角色視線、相機瞄準與對焦是三個不同決定。

鏡頭內連續轉彎使用可通行的 Bezier 或其他切線連續弧線，半徑依通道、障礙、主體距離與速度選擇。狹窄處要減速並逐步轉向。直角折線或密集關鍵影格不能形成平順轉彎。線性時間進度可以沿平順空間路徑前進；空間與時間插值分開處理。一般路標不必停下。

揭示過程中，移動注視目標或連續插值相機方向。位移、pan／tilt 與任何延遲都須分配到實際時間，並及早到位，讓新主體有可讀的停留。Damped Track 不是時間阻尼。連接鏡頭時，除了移除切點標記，也要接合位置、基礎朝向、鏡頭參數與手持相位。弧線應服務內容，不應吃掉內容時間。

視需要分開基本路徑／朝向、構圖修正、選用風格層與 Camera。Blender 相機通常沿局部 -Z 看出去，局部 Y 朝上；須檢查 Track To 軸與奇異姿勢。若要真正延遲，設定時間常數、pre-roll 與初始狀態，接著依序評估並 Bake，使跳轉或反向拖曳時間軸仍能得到確定結果。位移、pan／tilt、roll、焦距與對焦各有獨立控制責任。Bezier handle 可能過衝；四元數仍須維持符號一致、走最短路徑並控制 roll。切換 parent 或 Constraint 時保留世界變換。相機不必重現每一步的上下起伏。

手持與衝擊晃動是選用、帶固定 seed 的層，頻譜、幅度與衰減須一致。刻意的甩鏡、機械式轉向或突然切鏡，可以作為特定鏡頭的例外。不要強迫分離的機位連成穿牆的連續路徑。

## 局部驗證

轉彎、揭示或交接改變時，檢視附近一小段實際預覽。檢查畫面位置、大小、前方留白、資訊可見性、障礙與相機淨空、是否跨越動作軸線、基本速度與角度變化、注視目標連續性，以及足夠可讀時間。高速接近障礙時，應用相機體積掃掠或夠密的取樣涵蓋近裁切面淨空；一個未相交點不足夠。針對具體問題取有限影格或子影格樣本，不自動測全片。硬切是相機運動檢查的邊界。

若已選擇細緻腳底固定策略，應在支撐面局部座標比較腳部接觸點與支撐錨點，或比較兩者在同一相機中的投影殘差。不同深度不能只減去同一個全域像素相機位移。選定影格要在正向、反向及隨機跳轉下比較，確認評估具有確定性。記錄實際範圍與不確定性。只有路線或完整資料欄位，不能證明觀眾看得懂預定的接近動作。確認後不以這些檢查新增關卡。
