# 使用者審閱與提示詞交付

人工審閱後的後續流程以本文件為準。先前的訪談、劇本與分鏡共同展示、靜態確認及動畫確認，仍依[階段確認規則](production-approval-gates.md)辦理。

| 目前情況 | 下一步 |
|---|---|
| 只有靜態模型已確認 | 為約定的相機、主體與關鍵道具製作動畫；不可把動畫標成已確認 |
| 目前模型與動畫都已確認 | 採用該修訂版，撰寫完整 AI 影片提示詞，並匯出尚未完成的約定參考影片 |
| 模型或動畫需要修改 | 修訂受影響的 Blender 範圍、展示結果，保留無關的已確認決定 |
| 使用者只要提示詞、已有可用預演，或明確免除匯出 | 依實際素材交付文字，不虛構影片製作任務 |
| 生成結果的外觀、身分或細節有誤 | 先調整相關圖片、標籤或提示詞；只有結構改變才回到 Blender |

當「看起來可以」、「同意」或「就用這版」明確指向已展示的現行模型與動畫時，即可視為確認，並對應到產物與範圍。不要重複要求已清楚給出的確認。交付時不得另外要求碰撞檢查、Standard 或 Release、全片審閱、效能基準測試或額外算圖。既有技術證據應如實保留；人工確認不是腳本通過，未執行的腳本也不會推翻人工確認。

約定的匯出是交付內容的一部分。可沿用已確認修訂版的既有影片，或分小批匯出乾淨版本。只檢查儲存結果與媒體中繼資料，不重啟動畫的美學審閱。

利用既有紀錄辨識已確認版本。已知的手動修改，只有影響鏡頭、時間或事件文字時才同步。若確實無法辨識已確認檔案，只詢問缺少的定位資訊。新寫或修訂的提示詞仍須就地比對目前來源版本、主體、動作執行者、方向、時機與起訖狀態。交付前解決已知矛盾，不必重播或重算已確認影片。

資料檢查、畫面觀察、使用者確認與實際生成證據要分開記錄。局部取樣不能證明完整動作或觀看效果；檔案驗證也不能證明肢體左右或物理表現。未知事項若不阻礙目前任務，就保留為未知。使用者回報的輸出須標示為回報，不可宣稱是自己觀察到的。

缺少的角色美術與場景、道具資產一起準備。美術圖尚未完成時，可以交付內容完整的草稿與角色圖片提示詞，但不能把佔位檔稱為完成圖片。只缺外觀不需要重新製作 Blender。工程、影片、提示詞、外觀、上傳綁定與生成結果分開追蹤；約定素材或實際綁定仍缺時，不可宣稱交付已完整或可直接提交。

每份影片提示詞先說明各參考來源的用途，再寫具名角色與道具對照、已確認的鏡頭與聲音、概略時間段、必要表演及連續性。納入劇本的關鍵互動與結果。對白要交代可讀出的表情與語氣變化、觸發原因及傾聽者。段落內的動作自然銜接，不逐一轉寫所有微小動作。規劃中的 `@` 標籤須有檔案對照表；只有實際上傳的標籤才算綁定。

使用者若確認提示詞的結構或自然度，就保留該基準。後續若發生身分、入場或服裝錯誤，先局部診斷與修訂，再考慮重寫整份提示詞。不要自動啟動付費生成或重複產生變體。

區分「參考影片與提示詞已交付」和「最終 AI 影片已生成並剪輯」。若曾約定生成與剪輯但尚未完成，就列為待辦。若約定只到提示詞交付，說明使用者下一步。更新專案、章節進度、連續性與結尾狀態，但不因此啟動系列的其餘部分。
