# 場景語意細節庫

細節能幫助觀眾與影片模型辨識場所的用途、角色如何使用它，以及空間尺度。從功能物件、比例參照、路徑／邊界、動作道具及環境線索中，挑選少量有用元素。優先選擇會影響辨識、動作因果、遮擋或尺度的細節，避免隨意裝飾。

| 場景 | 可選的實用元素 |
|---|---|
| 都市街道 | 路緣、車道標線、號誌、招牌、店面、公車站、垃圾桶、護欄 |
| 住宅或公寓 | 入口、門牌、樓梯、扶手、信箱、沙發、餐桌、窗簾、燈具 |
| 辦公室 | 接待櫃檯、辦公桌、會議桌、螢幕、櫃子、玻璃隔間、門禁 |
| 零售／商業空間 | 門廊、結帳櫃檯、展示櫃、貨架、導引標示、排隊欄杆、座位 |
| 餐廳或酒吧 | 吧台、桌子、菜單、餐具、托盤、出餐口、酒架、服務通道 |
| 醫療場所 | 櫃檯、病床、簾幕、推車、診間標示、消毒設備、候診椅 |
| 工廠或倉庫 | 貨架、棧板、堆高機、管線、護欄、工作站、安全標線、裝卸門 |
| 學校或公共建築 | 走廊、公告欄、置物櫃、座椅、講台、標示、飲水機 |
| 交通場站 | 月台邊緣、閘門、售票機、座位、班次看板、行李、手扶梯 |
| 自然景觀 | 主要樹木、岩石、高低差、步道、倒木、水體、灌木叢、地標 |
| 動作／打鬥場地 | 掩體、可破壞物件、障礙、道具、高低差、狹窄通道、門窗 |
| 賭場／娛樂場所 | 導引標示、門禁、接待區、機台、桌台、籌碼、吧台、休息區、服務路線 |

以上只是候選元素，不是固定清單。依劇本、分鏡、預算與使用者的資產庫選擇。重複物件共用網格，或使用 Collection Instance／Geometry Nodes。遠景保留輪廓、色塊與尺度；前景動作道具須有接觸及操作表面。結構細節維持低面數，不自動加入高解析度貼圖或模擬。

每個新增元素都要記錄用途、所在區域、鏡頭可見性、碰撞角色與 LOD。逐鏡檢查：場景是否可辨識、能否支援動作與構圖、遮擋與穿模是否受控、重複物件能否實例化，以及代理細節是否可能被誤認為成片必備外觀。
