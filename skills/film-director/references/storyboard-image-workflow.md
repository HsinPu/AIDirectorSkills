# 漫畫式分鏡圖與參考路線

本分支把已確認的劇本與分鏡表畫成可審閱的連續畫面，再整理為影片生成的圖片參考。圖片提供構圖、景別、動作關係與順序；靜態格子不能證明實際運鏡速度、動作流暢度或精確接觸。

## 參考路線選擇

劇本與完整分鏡表確認後、開始製作參考素材前，以沿用的題號詢問；已選定路線、已有適用參考或明確委託時，直接沿用並記錄，不在每鏡重問。

> 這次要用哪種方式製作影片參考？
>
> A｜漫畫式分鏡圖：用圖片呈現遠近景、構圖、動作順序與運鏡。
> B｜Blender 預演：用簡化模型製作參考影片，呈現空間、走位與連續運鏡。
> C｜Hyper3D 素材＋Blender 預演：生成適合的靜態模型，再匯入 Blender 製作預演。

A 固定列第一，但不自動視為已選。依需求提出建議：構圖與動作順序可先用 A；需要觀看連續運鏡與空間關係時建議 B；有適合的不規則靜態物件才考慮 C，適用條件見 [Hyper3D](hyper3d-scene-assets.md)。C 仍使用 Blender，不是另一種影片生成模型。選路線不代表模型連線、付費模型生成或最終影片生成已獲授權。

記錄 `reference_method`：A 為 `storyboard_images`，B 為 `blender_previs`，C 為 `hyper3d_blender_previs`，並保存使用者回答、適用鏡頭／單元與修訂。舊專案依可靠紀錄辨識路線，無須補問或追溯重做。使用者要求混合時可逐單元記錄，但不因此增加審閱次數。

## 圖片路線的製作與審閱

1. 從現行分鏡表選出足以說明構圖改變、互動、揭露與結果的關鍵時刻。格數與頁數依故事需要，不固定六格、不按每秒一格。多鏡作品可分頁，仍是同批審閱。
2. 沿用實際角色、場景與道具來源。繪圖工具可用時使用適用的影像生成／編輯方式；純文字示意人物須明說，不能聲稱已使用角色照片。缺少的必要外觀素材可依[影像素材流程](reference-image-driven-assets.md)與本批分鏡一起準備；不要求圖片路線補齊僅供建模的多視角圖。
3. 繪製帶註解的審閱圖。每格畫幅與成片構圖一致；紙張版面可以不同。保留可讀的時間、景別及箭頭，足以分辨主體尺度、視角、接觸與動作因果。
4. 核對本批來源、身分、服裝、道具、左右關係、動作順序與文字，修正已知矛盾；檢查不等於使用者確認。完成整批後展示所有頁面及鏡頭／格子索引，一次審閱，不逐圖或逐格要求確認。
5. 確認後整理同版乾淨單格參考圖、時間與運鏡對照、完整提示詞及素材包。不再要求 Blender 連線、靜態場景或動畫審閱。只是清除註解與整理檔案，不另加創作審閱；若重繪改變構圖或動作，只重新展示受影響範圍。

每格至少登記穩定的 `panel_id`、`shot_id`、單元內 `time_seconds`、景別／機位、動作及 `cut_before`。運鏡箭頭與人物動作箭頭分開，圖例說清楚各自用途。實際切鏡才切換鏡頭 ID；同一長鏡頭的多格共用鏡頭 ID，註明「連續，不剪接」。格子排列是閱讀順序，不代表相鄰空間。

角色設定圖的固定版型不適用分鏡格；分鏡圖按鏡頭構圖繪製。角色臉部來源仍依[身分一致性規則](ai-video-and-asset-prompts.md#每份提示詞必寫臉部身分一致性)，原始角色影像負責身分，分鏡人物負責位置、服裝關係與動作，不把草圖臉當成替換身分。

## 審閱圖與生成參考分開

- **審閱圖**：可含格線、編號、時間、文字與箭頭，標為 `storyboard_review`。保存在製作／審閱目錄，供使用者理解全段。
- **生成參考圖**：同版構圖的乾淨單格，不含格線、文字、箭頭或浮水印，標為 `storyboard_frame`。移除標示時保留人物、道具、角度及狀態；只有裁切不足以去除疊在畫面中的箭頭。保存與審閱格的來源對照。

生成前查證目標模型、介面與模式對一般圖片參考、首尾幀、數量／順序及檔案的實際支援。一般參考圖不自動成為時間控制幀；API 接受圖片也不證明能遵照全部格子。以支援方式綁定已採用圖片，另用提示詞說明概略時間與連續動作。

超過來源上限時，先整理足以表達意圖的關鍵圖或依原分段計畫分包，登記省略與適用範圍，不默默丟失已確認的重要事件。需改變剪接、單元分段或參考策略時才詢問。多格參考板只有在實際介面可用且不致混淆來源用途時才考慮，不把帶箭頭的審閱頁直接當作成片首幀。不支援所需圖片控制時說明限制；不得宣稱已精確鎖定運鏡，也不自動補做 Blender 或付費影片。

## 提示詞中的來源角色

依實際綁定逐一指定：每張分鏡圖對應哪個鏡頭、時間與構圖，哪些圖是同一連續鏡頭的不同時刻；角色原圖提供誰的臉與服裝；場景／道具圖提供哪些外觀。最終媒介與美術依已確認設定，不能因參考是漫畫就自動變成漫畫影片。

可套用的來源說明，替換成實際人物、圖片與時間：

    分鏡來源只提供景別、機位、構圖、人物／道具位置與動作先後。
    所列關鍵格屬於同一連續鏡頭，自然連接，中間不增加切鏡或停格。
    不複製紙張、格線、註解、箭頭、草圖筆觸或漫畫畫風。
    最終影片採已確認的媒介、色彩、光線與自然表演。
    人物臉部與服裝依各自已登錄的角色影像，不以草圖替換身分。

上文「連續」僅套用於實際長鏡頭；多鏡作品逐一寫出已採用切點。標籤與檔案的對照依[提示詞範本](reference-prompt-template.md)，未上傳不宣稱已綁定。不能用通用 `@imageN` 假設每個 API 都有相同標籤語法。

## 素材包與接續紀錄

依[逐鏡素材包與生成單元](reference-video-delivery.md#逐鏡素材包與生成單元)保存各鏡與各單元實際引用的乾淨圖片、角色／外觀素材、完整提示詞與 manifest。同一長鏡頭的多格留在同一鏡頭包，不按格子製造新切鏡資料夾。單元清單逐格對應 `reference_id`、單元內時間及切點；相鄰單元仍記錄人物、道具、機位與聲音接點。

`project-state.json` 指向現行路線、分鏡表、審閱頁、乾淨單格清單及已核准修訂。以 `stage_reviews` 記錄 `storyboard_images` 的整批展示與使用者回覆；圖片、文字、上傳及影片生成分開追蹤。A 的 `.blend`、`blender_structure_ready`、靜態／動畫審閱及 `reference_video_status` 記為 `not_applicable`，不是缺失、已核准或明確免除。

可在生成單元內使用下列格子對照；`reference_method` 也可放在套件層級作為預設。此處省略一般 references 與單元提示詞欄位，完整格式見[離線交接檢查](offline-handoff-check.md#圖片路線套件)：

    "reference_method": "storyboard_images",
    "storyboard_panels": [
      {"panel_id": "PN01", "shot_id": "SH01", "reference_id": "SB1",
       "time_seconds": 0, "cut_before": false},
      {"panel_id": "PN02", "shot_id": "SH01", "reference_id": "SB2",
       "time_seconds": 3, "cut_before": false}
    ]

已有分鏡可在使用者要求下補做 Blender 預演，沿用未變的故事、鏡頭與素材。新增路線須完成其適用的靜態／動畫審閱，不能把已確認圖片當作不存在的 Blender 動畫確認。
