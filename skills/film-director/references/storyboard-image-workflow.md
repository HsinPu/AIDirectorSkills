# 漫畫式分鏡圖與參考路線

本分支把已確認的劇本與分鏡表畫成可審閱的連續畫面，再整理為影片生成的圖片參考。圖片提供構圖、景別、動作關係與順序；靜態格子不能證明實際運鏡速度、動作流暢度或精確接觸。

## 參考路線選擇

劇本與完整分鏡表確認後、開始製作參考素材前，以沿用的題號詢問；已選定路線、已有適用參考或明確委託時，直接沿用並記錄，不在每鏡重問。

> 這次要用哪種方式製作影片參考？
>
> A｜漫畫式分鏡圖：每鏡一張、每張六格，逐格看清那幾秒的遠近景、動作與運鏡。
> B｜Blender 預演：用簡化模型製作參考影片，呈現空間、走位與連續運鏡。
> C｜Hyper3D 素材＋Blender 預演：生成適合的靜態模型，再匯入 Blender 製作預演。

A 固定列第一，但不自動視為已選。依需求提出建議：構圖與動作順序可先用 A；需要觀看連續運鏡與空間關係時建議 B；有適合的不規則靜態物件才考慮 C，適用條件見 [Hyper3D](hyper3d-scene-assets.md)。C 仍使用 Blender，不是另一種影片生成模型。選路線不代表模型連線、付費模型生成或最終影片生成已獲授權。

記錄 `reference_method`：A 為 `storyboard_images`，B 為 `blender_previs`，C 為 `hyper3d_blender_previs`，並保存使用者回答、適用鏡頭／單元與修訂。舊專案依可靠紀錄辨識路線，無須補問或追溯重做。使用者要求混合時可逐單元記錄，但不因此增加審閱次數。

## 圖片路線的製作與審閱

1. 依現行分鏡表建立「每鏡一張分鏡頁、每頁六格」的製作清單，逐格規劃時間、景別、構圖、動作及運鏡。六鏡就是六張、共三十六格；不要將六鏡合成一張六格圖，也不要只交付每鏡一張單格代表圖。使用者另有明確版面要求時，記錄並採用該要求。
2. 沿用實際角色、場景與道具來源。繪圖工具可用時使用適用的影像生成／編輯方式；純文字示意人物須明說，不能聲稱已使用角色照片。依[起始畫面資產](start-frame-assets.md)準備每個生成片段的成片風格起始圖，缺少的必要外觀素材依[影像素材流程](reference-image-driven-assets.md)與本批分鏡一起準備；起始圖與六格頁一起展示、確認，不要求圖片路線補齊僅供建模的多視角圖。
3. 依下節規格繪製各鏡獨立的六格審閱頁，保存在各自鏡頭資料夾並保留實際提示詞及來源。每格畫幅與成片構圖一致；紙張版面可以不同。
4. 核對實際圖面的每鏡頁數、每頁格數、時間遞進、來源身分、服裝、道具、左右關係、動作／運鏡順序與文字，修正已知矛盾；檔案數正確不代表每張格數正確，檢查也不等於使用者確認。完成整批後展示所有頁面、鏡頭／格子索引及逐格時間與運鏡對照，一次審閱，不逐圖或逐格要求確認。
5. 確認後直接把各鏡完整六格運鏡原頁複製到該鏡素材包的 `media/`，與已準備的起始圖、所需已選定人物參考圖、場景及道具圖片一併列為影片 AI 輸入；交付全部格子的時間／運鏡對照與完整提示詞。沿用已確認原檔，不另生成代表單格替代完整頁、不縮減成一兩張代表圖，不要求 Blender 或動畫審閱。起始圖是先前圖片批次的獨立成片素材，不是整理時另重畫的運鏡頁。單純複製與整理不另加創作審閱；只有受影響的創作或參考策略變更才更新相應確認。

## 每鏡一頁六格的預設規格

- **一頁只屬於一個鏡頭。** 預設兩欄三列，從左上、右上、中左、中右、左下到右下依序閱讀。頁首標示鏡頭 ID、名稱與全片起訖秒數；同頁六格共用 `shot_id`，註明「同一鏡頭，連續，不剪接」。實際切鏡才切換鏡頭 ID，格子排列不代表相鄰空間。
- **六格呈現時間推進。** 選出起始、發展、轉折與結果等六個關鍵時刻，覆蓋該鏡的起訖狀態。時間依動作與停留需要分配，不按每秒一格，也不必等距；不為湊格數新增劇情、動作或切鏡。安靜段落可呈現同一構圖的持續、眼神、呼吸或環境變化，明寫保持狀態，不能用六張相同畫面冒充有進展的動作。
- **逐格畫出攝影機的變化。** 每格標示時間、景別、機位及本段運鏡，例如跟拍、推近、拉遠、橫移、環繞或固定；構圖須實際對應人物大小、視角與前後景關係的變化。固定機位維持視角與尺度，用人物、道具或環境進度表達時間，不為填六格擅自加入推拉或切換角度。
- **動作與運鏡分開標示。** 預設橘色實線箭頭表示人物／車輛／道具動作，藍色虛線箭頭表示攝影機移動，附清楚圖例；固定機位標「固定」。箭頭與文字避開臉部、接觸點及重要動作，不讓同一箭頭兼指人物與相機。
- **區分頁數、格數與片長。** 審閱清單分別記錄鏡頭數、頁數、各頁格數與總格數；預設 N 鏡對應 N 頁、6N 格，影片仍沿用已確認的鏡長與剪接。使用者指定其他版型時記錄實際數量及原話；既有已確認產物不因更新 Skill 自動重畫。

每格至少登記穩定的 `panel_id`、`shot_id`、`page_id`、頁內序號、全片 `global_time_seconds`、鏡內 `shot_time_seconds`、景別／機位、動作、運鏡及 `cut_before`。頁面預設顯示全片秒數，對照表另列鏡內秒數；各鏡的時間須遞增並落在該鏡區間。尚未分配生成單元時不虛構單元時間；分包後另填 `unit_id` 與單元內 `time_seconds`，不可直接混用全片秒數。首次鏡頭指派不是切鏡；同鏡後續格的 `cut_before` 都為 `false`。

角色設定圖的固定版型不適用分鏡格；分鏡圖按鏡頭構圖繪製。角色臉部來源仍依[身分一致性規則](ai-video-and-asset-prompts.md#每份提示詞必寫臉部身分一致性)，原始角色影像負責身分，分鏡人物負責位置、服裝關係與動作，不把草圖臉當成替換身分。

## 完整運鏡頁的生成參考用途

- **完整運鏡參考頁是預設輸入。** 將已確認的每鏡六格原圖複製到各鏡 `media/`，保留全部格子、箭頭及時間文字，與已選定人物參考圖一併提供給影片 AI。交付清單使用 `storyboard_sequence_page`，記錄來源頁、鏡頭 ID、`panel_count`、各格 ID、頁內序號及時間對照，標明 `input_to_video_ai: true`。這是既有檔案的採用用途，不是新影像生成任務。
- **僅供審閱的資料另行標示。** 未採用或歷史草稿使用 `storyboard_review`，不列入本次生成輸入。完整頁已採用為運鏡來源時，在生成清單中使用 `storyboard_sequence_page`，不能僅因含格線或箭頭就排除它。原製作及審閱紀錄仍保留。
- **乾淨單格與首尾幀是條件分支。** 只有使用者明確要求，或所選模式已查證需要首尾幀／獨立格且參考策略變更已確認時，才另行準備 `storyboard_frame`。優先沿用適用的既有檔案，保留來源格與用途；不默默刪除完整頁、不省略六格動作，也不把整理檔案當成重新生成替代構圖的授權。
- **圖上輔助標示說明意圖，成片不重現輔助標示。** 提示詞交代閱讀順序、格子時間、動作箭頭與運鏡箭頭，採用構圖、走位及攝影意圖，排除格線、箭頭、註解、紙張及漫畫版面；保留劇本已要求的遊戲 HUD、小地圖與任務標示。人物身分與服裝以各自已選定人物參考圖為準，依[人物來源規則](character-image-assets.md#人物參考的選用與交付)沿用設定圖或原照；成片開場風格與構圖另由起始圖提供。

提交前查證目標模型、介面與模式對一般參考、完整多格頁、首尾幀及來源數量的實際支援。完整頁用作結構與順序參考，不直接當首幀；API 接受圖片也不證明會遵照全部格子或精確時間。未選定模型時先完成原檔素材包與預定來源表，不自動改為拆格或重繪。

來源上限或模式限制會影響已採用方案時，保留完整原頁，說明具體限制與需要變更的輸入範圍，依已確認的參考策略處理。不默默只選一兩格、改剪接、補做 Blender 或啟動付費生成；單純複製原檔與登記來源不增加審閱點。

## 提示詞中的來源角色

依實際綁定逐一指定：每張分鏡圖對應哪個鏡頭、時間與構圖，哪些圖是同一連續鏡頭的不同時刻；已選定人物參考圖提供誰的臉與服裝；場景／道具圖提供哪些外觀。最終媒介與美術依已確認設定，不能因參考是漫畫就自動變成漫畫影片。

可套用的來源說明，替換成實際人物、圖片與時間：

    分鏡來源只提供景別、機位、構圖、人物／道具位置與動作先後。
    所列關鍵格屬於同一連續鏡頭，自然連接，中間不增加切鏡或停格。
    不複製紙張、格線、註解、箭頭、草圖筆觸或漫畫畫風。
    最終影片採已確認的媒介、色彩、光線與自然表演。
    人物臉部與服裝依各自已登錄的角色影像，不以草圖替換身分。

上文「連續」僅套用於實際長鏡頭；多鏡作品逐一寫出已採用切點。標籤與檔案的對照依[提示詞範本](reference-prompt-template.md)，未上傳不宣稱已綁定。不能用通用 `@imageN` 假設每個 API 都有相同標籤語法。

## 素材包與接續紀錄

依[逐鏡素材包與生成單元](reference-video-delivery.md#逐鏡素材包與生成單元)將完整運鏡頁與該鏡實際需要的人物／外觀圖片放入 `media/`，另存完整提示詞及 manifest。預設每鏡一張完整頁，六鏡就是六個包內各一張六格圖；不按格子建立新切鏡資料夾。每個生成單元同樣保存需要的原頁與人物來源，避免只附人物圖片、把運鏡頁留在上一層或只當審閱附件。

`project-state.json` 指向現行路線、分鏡表、完整原頁、逐格時間／運鏡對照及已核准修訂。清單分開記錄 `shot_count`、`page_count`、每頁 `panel_ids` 與總 `panel_count`，預設 `panels_per_page: 6`；條件性單格另列，不取代原頁。圖片可用、提示詞、實際上傳／綁定與影片結果分開追蹤。A 的 Blender 專屬產物及審閱記為 `not_applicable`。

同一完整頁的六格共用 `reference_id`，以 `panel_number` 區分頁內位置；單元內 `time_seconds` 與全片／鏡內時間分開登記。下例只示意同一連續鏡頭的六格，完整來源及單元格式見[離線交接檢查](offline-handoff-check.md#圖片路線套件)：
